Projects

Full-Stack / Machine Vision

RBoticsDepth: AI Component Scanner

A cross-platform app that identifies electronic components from a photo and generates a buildable project around them, with guided theory and Git setup for beginners.

Users photograph their parts and a vision model identifies each component, sorting them into a personal Component Locker and generating a project tailored to what they already own. A FastAPI backend handles image analysis, while Supabase provides authentication and a Postgres database with row-level security, serving both a web dashboard and a mobile app. Engineering challenges included server-side rate limiting to control API costs, and fixing a race condition where fast double-taps triggered duplicate scans, solved with a synchronous re-entrancy guard.

Tech: Python · FastAPI · Gemini · React Native (Expo) · Supabase · Streamlit

In active development · Source available on request

Bio-Inspired Robotics

Sim-to-Real Path Integration

Investigating how a ring-attractor neural model of path integration, inspired by how mammals track their position, holds up when moved from simulation onto a physical wheeled robot.

Most research in this area stays in simulation. This final year project builds a vision-based wheeled robot to measure how real-world sensor and actuation noise degrade drift correction compared with simulated noise, benchmarked against conventional approaches such as Kalman filtering.

Tech: ESP32 · Camera ·
